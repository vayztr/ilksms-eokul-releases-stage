## 🧪 Test kurulumu

**Windows:** [ilksms-eokul-Setup.exe »](https://github.com/vayztr/ilksms-eokul-releases-stage/releases/latest/download/ilksms-eokul-Setup.exe) — indirip çift tıklayın.

Bağlantılar her zaman en son test sürümünü verir. Uygulama **api-stage** (test) sunucusuna bağlanır.
